**Meridian Courier — Skyferry Archipelago.** An original flight game for the desktop browser: fly the Skyferry SF-2 "Petrel" across a named archipelago of six islands, threading golden gates on the Ring Run, carrying glass cargo to the Porto Lume strip, and riding a storm tailwind home on a low tank. A hand-written 3D projection renderer paints the heightfield terrain, the harbour town, two lit runways and the mission rings; the panel carries a working attitude indicator, altimeter, airspeed dial, compass ribbon and throttle/fuel/hull gauges, and the HUD always shows altitude, speed and heading. Throttle and bank discipline, fuel and hull, gear and touchdown ratings make every sortie a set of decisions. No network, no build step — static files only.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Fly with the arrow keys or WASD, G for gear, C for the cockpit camera, M for the next mission, Enter to start.
